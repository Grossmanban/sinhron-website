Verify your download

Every release is published with a SHA-256 checksum. Compare it before you install:

# macOS / Linux
shasum -a 256 Sinhron-*.dmg

# Windows (PowerShell)
Get-FileHash .\Sinhron-*.msix -Algorithm SHA256

Signed builds and reproducible-build details will be added as release signing is set up.
