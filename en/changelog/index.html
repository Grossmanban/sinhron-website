Notable changes, release by release.

October 2026 — early beta

There are no public releases yet. Here’s what’s in the code today:

  • Messages: an iMessage-style menu, reactions, swipe to reply, edit and delete, pins, formatting and spoilers, on-device search.
  • Media (in beta): photos and albums, a full-screen gallery, video, documents, voice messages with lock, link previews.
  • Privacy: disappearing messages from 5 minutes to 4 weeks, Face ID / Touch ID lock, app-switcher cover, a real 60-digit safety number.
  • Groups: @mentions with an @ badge, profile photos shared inside the encryption, notes when someone records the screen in a chat with disappearing messages (not yet tried on a real iPhone).
  • Calls: 1:1 audio and video, end-to-end encrypted with SFrame; TURN over port 443 for strict networks.
  • Appearance: System, Light, Dark and Black (OLED) themes, six accents, English and Russian, VoiceOver and Dynamic Type.
  • Website: this website and documentation.
