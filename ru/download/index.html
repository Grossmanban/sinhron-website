Проверьте файл

Каждый релиз публикуется с контрольной суммой SHA-256. Сверьте её перед установкой:

# macOS / Linux
shasum -a 256 Sinhron-*.dmg

# Windows (PowerShell)
Get-FileHash .\Sinhron-*.msix -Algorithm SHA256

Подписанные сборки и данные для воспроизводимой сборки появятся, когда будет настроена подпись релизов.
